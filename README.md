# videobgremover

Локальный инструмент: вырезание фона по хромакею с превью в браузере и экспортом через FFmpeg (VP9 с альфой или MOV ProRes 4444). Есть обрезка по времени, зеркало и перемотка.

## Запуск для разработки

```bash
npm install
npm run dev
```

Откройте в браузере **http://localhost:5173** (API на порту **8787**).

## Сборка и запуск как приложение

```bash
npm run build
npm start
```

После сборки один процесс отдаёт интерфейс и принимает `POST /api/export`.

Для стабильного превью в браузере удобны файлы **MP4 (H.264)** или **WebM**.
